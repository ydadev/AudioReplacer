AudioReplacer Portable 1.0
==========================

Удобная программа для объединения видео и внешней озвучки сериалов и аниме.

1. Запустите AudioReplacer.exe.
2. Если FFmpeg не найден рядом с программой, ознакомьтесь с лицензией.
3. Выберите автоматическую загрузку или скачайте ffmpeg.exe и ffprobe.exe
   самостоятельно и положите их рядом с AudioReplacer.exe.
4. Выберите папку с видео и аудио.
   Аудиодорожки могут находиться во вложенных подпапках.
5. Нажмите «Найти пары», затем «Заменить звук».

Вкладка «Убрать аудиодорожки» сканирует видео с несколькими встроенными
дорожками. Выберите одну сохраняемую дорожку для каждого файла и нажмите
«Удалить остальные аудиодорожки». Если одинаково названная дорожка есть
во всех файлах, её можно выбрать сразу для всех.

При автоматической загрузке FFmpeg сохраняется рядом с программой.
Для записи в эту папку должны быть права.

FFmpeg не включён в этот архив.
Лицензия: https://ffmpeg.org/legal.html
Ручная загрузка: https://github.com/BtbN/FFmpeg-Builds/releases
